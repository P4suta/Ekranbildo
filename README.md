# Ekranbildo

Capture and edit macOS screenshots with automatic annotation placement.

## Installation

```sh
git clone https://github.com/P4suta/Ekranbildo.git
cd Ekranbildo
mise install
```

## Usage

```sh
swift run --package-path Tools ekranbildo-dev check
```
